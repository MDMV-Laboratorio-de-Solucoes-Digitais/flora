## 3. Primary-source verification (Rust release blog)

- **Rust 1.98.1 fixed the trait-object vtable UB — CONFIRMED.** Official post
  https://blog.rust-lang.org/2026/09/03/Rust-1.98.1/ (Sept. 3, 2026) states: "Rust 1.98.1 fixes a
  miscompilation in vtable generation. In Rust 1.98.0, in some circumstances, rustc would
  incorrectly generate a trait object vtable with a null pointer where a function pointer should
  be. This leads to undefined behavior in the emitted code … may 'just' cause segfaults … possible
  … justification for arbitrary effects (as is typical for UB)." Exact claim verified verbatim.
- **Current stable is 1.100.0 — CONFIRMED.** Official release list
  https://blog.rust-lang.org/releases/ shows "Nov. 12 — Announcing Rust 1.100.0" as the newest
  release; announcement https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/ confirms 1.100.0 is
  stable (never type, allocator API, DropGuard, Cargo unused-dependency reporting, etc.).
- Release timeline (primary): 1.98.0 = 2026-08-20; 1.98.1 = 2026-09-03; 1.99.0 = 2026-10-01;
  1.99.1 = 2026-10-15; 1.100.0 = 2026-11-12. Flora's `1.98.0` pin is exactly the defective release.

## 4. Clippy-gate risk analysis

Strict gates (`.github/workflows/rust.yml`): line 27
`cargo clippy --workspace --all-targets -- -D warnings` and line 161
`cargo clippy -p flora-core --bin flora-mint-session --features dev-mint -- -D warnings`.
Everything after `--` is passed to rustc/clippy, so **`-D warnings` promotes any new warn-by-default
lint to an error** — a new lint firing on existing code breaks CI.

- **1.98.0 → 1.98.1 (patch):** bug-fix-only point release; no new clippy lints. Risk ≈ 0.
  Also note `rust:1.98-slim` (Dockerfile) is a floating minor tag that already resolves to the
  latest 1.98.x (i.e. 1.98.1), so the Docker path is likely already patched; the exact `1.98.0`
  CI pin is the real exposure.
- **1.99.1:** one minor of new lints, but prior research records the local toolchain as
  `cargo 1.99.1`, so there is empirical evidence the strict gate tolerates 1.99.x. Low risk.
- **1.100.0:** highest risk. Adds a warn-by-default Cargo `unused_dependencies` lint and a
  Cargo build-dir layout change that can break build processes/tests with workarounds; many new
  lints/APIs. Edition-2024 code is unaffected by the pre-2024 never-type-fallback change, but
  1.100.0 is 4 days old at research time — not the "safest" choice for an archived repo.

## 5. Recommendation

**Minimal, safest target: Rust 1.98.1 (exact).** It is the smallest possible change that removes the
documented UB, is a pure bug-fix release (no new clippy lints → strict gate unaffected), and aligns
CI with what the floating `rust:1.98-slim` Docker tag already effectively uses. Alternative if a
less-stale target is wanted: **1.99.1** (locally validated at the strict gate). **Do not jump
straight to 1.100.0** in this archived repo — decoupling the UB fix from newest-feature churn is
the lower-risk path; treat 1.100.0 as a separate, explicitly tested change.
