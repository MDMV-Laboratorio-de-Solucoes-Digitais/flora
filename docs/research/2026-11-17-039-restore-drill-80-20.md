## 2. Fundamentação do objetivo (Macro, 14 fontes primárias — `15-macro-deep-dive.md`)

- Macro Inc (antiga CoParse), `github.com/macro-inc/macro`: **6.354 stars, AGPL-3.0 desde
  31/05/2026** ("fully open source, not open core"), ~2,9 GiB de árvore. Stack: SolidJS
  1.9.7 + Vite 8 + Bun + Tauri 2; backend Rust (~200 crates / ~50 serviços) com Axum 0.8,
  async-graphql 7, SQLx/Postgres; realtime = Loro CRDT + WebSocket/Kafka; sync via
  **Cloudflare Workers + Durable Objects + D1 + R2 + KV** (`wrangler.toml`).
- Dependências caras (evidência de arquivo): AWS SDKs + CloudFront + LocalStack, FusionAuth,
  Doppler, PostHog, Datadog/OTLP, Stripe, Pipedream, LiveKit, Pulumi/AWS, Kafka/MSK,
  OpenSearch, Redis, forks git de `turso_core`/`libsignal`/`tungstenite`. Editor: Lexical
  0.45 com 13 overrides/3 patches.
- Footprint local exige Docker + 7 infraestruturas + Nix + Linux; testes nativos com
  `MemoryMax=6G`, "computers" reservam 7 GB + 32 GB Docker. **"Qualquer VPS barata" NÃO
  roda o stack completo do Macro** (conclusão verificada).
- **Implicação:** não forkar/clonar (AGPL exige abrir derivados). Reimplementar limpo só o
  grafo entidades+properties+backlinks e sync CRDT em Rust/Postgres, mantendo FTS do Postgres
  como autoridade e entregando **um binário + Postgres**.

## 4. Pesquisa multilíngue e correções de evidência (agentes 01–10)

Pesquisa em EN, PT, ES, FR/DE, ZH, JA/KR sobre dark factories, SDD e verificação. Correções
obrigatórias à doutrina do hub (consolidadas em `/tmp/opencode/dark-factory-80-20/00-methodology-synthesis.md`):

1. **NBER 35275**: Fig. 1 contém 25,5× LOC (+2450%); abstract traz commits +240% →
   projetos +80% → releases +30%. Working paper não revisado; dois autores são consultores
   pagos da Microsoft (marcar como tal).
2. **LLM-judge**: 7–17% em replicações idênticas (Kumar et al., arXiv:2610.12083); contra-
   argumento é **25–71%/62–91%** (Zhao et al., arXiv:2608.12645), não "7–34%".
3. **BCG 3–5x** = relato, não benchmark independente (a própria Sonar o classifica assim).
4. **Gargalo = verificação**: Harvard (718 firmas / 725.938 trabalhadores) — código +30%,
   PRs +23%, mas *issues deployadas* inalteradas; tempo PR→merge +49%.
5. **SDD é condicional**: vence em tickets ≥6 arquivos (80% vs 50%), não compensa em
   bug-fix/refactor/test. SpecMine (arXiv:2608.25202): 470.795 specs / 73.030 repos — custo
   migra para planejamento. **Implicação ao Flora:** cerimônia SDD só para mudanças
   estruturais; limpeza mecânica usa gate determinístico curto ("teste do diff"/ODD).
6. **Nível 5 não tem caso verificado**; o degrau real é L3→L3.5 com gate de evidências por
   classe (pass-rate >90%, FP <5%, override <10%, ≥20 PRs), verificador author-blind.
7. **Verificação independente**: SWE Refactor Bench — só 28/520 runs (5,4%) passam auditoria
   + testes + verificação independente (arXiv:2608.23564).
