# Research 035 — Global landscape: Macro & self-hosted alternatives (2026-11-16)

**Method:** 12+ searches (websearch quota exhausted → DuckDuckGo fallback) + 30+ fetches; primary sources prioritized. EN/PT/ES/DE/FR/JA/ZH searched. **All sources accessed 2026-11-16** unless noted. Confidence marked per claim.

## Executive summary

1. **Macro is a hyper-active, well-funded commercial product, not a dormant reference.** Repo created 2025-11-08, last push 2026-11-16, 8,881 commits, 6,353★, 597 forks, 452 open issues, ~3.0 GB, Rust+**SolidJS** (not Svelte), AGPL-3.0 ([repo](https://github.com/macro-inc/macro), [API](https://api.github.com/repos/macro-inc/macro), 2026-11-16; **high**). 170k+ users, ~$30M raised (a16z), $0/$40/$200 per seat, hosted-first ([FAQ](https://docs.macro.com/faq.md), 2026-11-16; **high**).
2. **Debloat thesis strongly supported:** Macro's own local stack = Nix + Postgres + Redis + LocalStack + OpenSearch + Kafka + FusionAuth + Cloudflare Durable Objects + OpenBao + LGTM tracing; optional "macro computers" reserve ~7 GB each ([running-locally.md](https://raw.githubusercontent.com/macro-inc/macro/main/docs/development/running-locally.md), 2026-11-16; **high**). Not a 2 vCPU/4 GB app.
3. **Biggest tailwind = incumbent licensing churn:** Macro BSL→AGPLv3 (2026-05-31); Mattermost v11 (Oct 2025) cut free compiled edition 1,000→250 users; NocoDB → non-OSI "Sustainable Use License" (2026-01-29); AppFlowy-Cloud archived; Outline BSL; Focalboard unmaintained (sources in §C; **high**).
4. **Gap narrowing:** Docmost, Zulip, Nextcloud, Plane, Twenty, AFFiNE cover pieces. Flora's wedge = **single-node, Postgres-authoritative, fully-AGPL, low-RAM workspace** — but 2 vCPU/4 GB is still NV in the repo.
5. **Risks:** operator time, AGPL bans, Rust 14.8%/Svelte 7.2% usage ([SO 2025](https://survey.stackoverflow.co/2025/technology), 2026-11-16; **medium**), competing with Macro's graph+memory, not its surface.

## Key findings by theme

### A. Macro: state, scope, license, weight
- **Activity:** 2026-11-16 commits touch FusionAuth, OpenSearch mapping, agent-harness, passwords ([API](https://api.github.com/repos/macro-inc/macro/commits?per_page=10), 2026-11-16; **high**). ~12 core contributors >100 commits, long tail 1–6 ([API](https://api.github.com/repos/macro-inc/macro/contributors?per_page=30), 2026-11-16; **high**).
- **Scope expanding:** email, chat, tasks, CRDT docs, canvas, agents+memory, calls, files, PRs, CRM, databases, calendar; docs add spreadsheets, forms, routines, skills, "<50ms" search, MCP ([README](https://raw.githubusercontent.com/macro-inc/macro/main/README.md), [llms.txt](https://docs.macro.com/llms.txt), 2026-11-16; **high**).
- **License/business:** AGPL-3.0, "not open core"; self-host allowed but "hosted is our primary focus"; hosted has mobile apps, AWS, SOC 2 Type II; HIPAA/FedRAMP → self-host@macro.com; **BSL→AGPLv3 on 2026-05-31** ([FAQ](https://docs.macro.com/faq.md), 2026-11-16; **high**). `releases` API empty → tag cadence unverified (**low**).
- **Deployment weight:** Nix only host dep; local stack = Postgres, Redis, LocalStack, **OpenSearch**, **Kafka**, **FusionAuth**; sync uses Cloudflare Durable Objects/KV/R2/D1; Passwords uses OpenBao+Raft; default LGTM tracing; computers need Docker/Incus, 7 GB reserve, 32 GB local memory; probes `MemoryMax=6G` ([source](https://raw.githubusercontent.com/macro-inc/macro/main/docs/development/running-locally.md), 2026-11-16; **high**). A *dev* stack; "far beyond Flora's Seed" is inference, not proof of impossibility (**medium**).
- **Honest 80/20 today:** identity/tenancy, channels+messages, light tasks, basic files, PG FTS, in-app notifications, simple compose/backup; defer email sync, calls, CRM/databases, canvas, agents/memory, deep integrations (Flora's ROADMAP). Differentiate operationally, not by parity.

### C. 2025–2026 shifts + multilingual evidence
- **Supports Flora:** Macro→AGPL; Mattermost free binary capped; NocoDB left OSI; AppFlowy OSS server archived; Outline BSL; Focalboard dormant; Plane/Docmost added paid tiers → priced-out users reachable.
- **Challenges:** Nextcloud, Rocket.Chat, Zulip, Plane, Twenty, Docmost are highly active with mature installers. "Self-hosted" alone is no moat; the wedge is **SaaS price × small-VPS operability × AGPL purity**.
- **Multilingual:** EN/PT/ES/DE/FR/JA/ZH searches ("alternativa self-hosted ao Macro", "suíte autoalojada pymes", "selbst gehostete Kollaborationssuite", "alternative auto-hébergée", "セルフホスト コラボレーション", "自托管 协作 套件") returned mostly listicles (ONES, ONLYOFFICE, Appvizer, IONOS, AFFiNE JA, SILL 2026) used only as leads. **FR/DE/ZH stress sovereignty/GDPR/数据主权; EN/PT stress cost.** No credible non-English "Macro alternative" debate → Macro looks EN-centric (**medium**).

## Contrarian views / risks

1. **"Self-hosting isn't worth it for SMB."** 5 h debugging a container, ~$360/yr per 250 W server, cognitive load ([How-To Geek](https://www.howtogeek.com/self-hosting-isnt-free-the-hidden-costs-nobody-talks-about/), pub. 2025-09-10, accessed 2026-11-16; **medium** — homelab anecdote). Flora's answer: one compose file, restore drill, no Nix/9-container stack.
2. **"Postgres-only is enough" has limits.** PG18: tsvector <1 MB, lexeme <2 KB, positions ≤16,383 ([PG](https://www.postgresql.org/docs/current/textsearch-limitations.html), 2026-11-16; **high**); Meilisearch lists nine gaps ([blog](https://www.meilisearch.com/blog/postgres-full-text-search-limitations), 2026-11-16; **medium**, vendor). Seed OK; CJK/i18n/ACL/ranking remain NV.
3. **AGPL adoption risk.** Google: AGPL code "MUST NOT be used at Google"; "viral" network-triggered source duty; deliberately broad ban ([policy](https://opensource.google/documentation/reference/using/agpl-policy/), updated 2026-11-04; **high**). Mitigation precedent: Twenty's §7 exception.
4. **Talent pool.** SO 2025 (all/professional): Rust 14.8%/14.5%, Svelte 7.2%/6.9%, Axum 2.8%, PG 55.6%/58.2% ([survey](https://survey.stackoverflow.co/2025/technology), 2026-11-16; **medium** — usage ≠ cost).
5. **80/20 may be commodity.** Chat+docs+tasks covered by Docmost+Zulip+Plane; Macro's value is the @-graph+memory. Without a graph primitive: "smaller Docmost with chat" (**low-medium**, hypothesis).
6. **License angle can be undercut.** Macro AGPL self-host is free; Mattermost source stays compilable; legal objections may not drive SMBs (**high**).
